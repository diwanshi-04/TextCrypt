# 🔐 TextCrypt

## Project Introduction

**TextCrypt** is an Android application for encrypting and decrypting text using modern cryptographic algorithms. It provides a simple interface for securing sensitive information and experimenting with different encryption techniques.

## Features

* 🔒 AES, DES and RSA encryption
* 🧑‍💻 Simple Android user interface
* ⚡ Encryption and decryption of text
* 🗝️ Key generation and management
* 📤 Easy sharing of encrypted data
* 🚀 Lightweight and easy to use

## How Does It Work?

1. **Choose an Algorithm:** Select the available encryption algorithm.
2. **Enter Data:** Enter the text you want to encrypt or decrypt.
3. **Provide a Key:** Generate or enter the required encryption key.
4. **Encrypt/Decrypt:** Perform the selected operation.
5. **Share:** Share the resulting encrypted text when required.

## Tech Stack

* Android Studio

## Use Cases

* Secure personal notes
* Protect sensitive text
* Share encrypted messages
* Learn about practical cryptography
* Experiment with encryption and decryption

## How to Install

```bash
git clone https://github.com/diwanshi-04/TextCrypt.git
cd TextCrypt
```

Then open the project in **Android Studio**, allow Gradle to sync, and run the application on an emulator or Android device.
